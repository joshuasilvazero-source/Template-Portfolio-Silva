# Project handoff checklist

**Client:** [NAME] | **Site:** [URL] | **Launch date:** [DATE]

## Before launch
- [ ] All pages from the Scope are complete and approved
- [ ] Tested on iPhone Safari, Android Chrome, desktop Chrome, Safari, Firefox and Edge
- [ ] Tested at phone, tablet and desktop widths with no horizontal scrolling
- [ ] Keyboard navigation works, focus is visible, images have alt text, color contrast passes
- [ ] All links and buttons work (no placeholder or dead links)
- [ ] Contact form tested end to end, and the client received the test inquiry
- [ ] Page titles, meta descriptions and social preview image set
- [ ] Favicon set
- [ ] Sitemap and robots.txt present
- [ ] Lighthouse run on the preview, with any major issues fixed
- [ ] No console errors
- [ ] No secrets or API keys in client-side code
- [ ] Third-party content (fonts, images) licensed for use
- [ ] Final 50% invoice paid

## Launch
- [ ] Domain connected, HTTPS working
- [ ] www and non-www redirect to one canonical version
- [ ] Old URLs redirected (redesigns)
- [ ] Sitemap submitted to Google Search Console (client-owned property)
- [ ] Final check of the live site

## Handoff
- [ ] Walkthrough call held (recorded if the client wants)
- [ ] Client has owner access to domain, hosting and all accounts, all in the client's name
- [ ] My access reduced or removed (unless on a care plan)
- [ ] Source files delivered (repository transfer or ZIP) as agreed
- [ ] Short "how to update your site" notes delivered
- [ ] Warranty period explained ([14] days for defects in scope)
- [ ] Care plan offered (optional)
- [ ] Asked for permission to show the project in my portfolio, and for a testimonial if they are happy
